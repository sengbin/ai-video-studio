## 镜头要求

- {{shotRules}}
- 每个镜头只表现一个连续的画面和一个主要动作；场景、时间或视角发生变化时另起镜头，并用 sceneLabel 标注所属场次。镜头的动作量要和时长匹配，2 到 5 秒的镜头只放一个简单动作。
- 镜头语言分别填在 shotSize（景别）、cameraAngle（机位与视角）、cameraMovement（摄影机运动）里，用具体的口语写，例如“大远景”“中景”“特写”“低角度仰拍”“平视”“24mm 广角”“固定镜头，摄影机静止”“推近”“拉远”“环绕”“手持跟拍”；三个字段都要填写。生成视频时程序会把它们写在提示词的最前面，所以 promptZh 里不要重复镜头语言。
- action 写清楚主体、动作和环境。
- promptZh 是直接用于视频生成模型的提示词，按进阶公式“主体（描述）+ 场景（描述）+ 运动（描述）+ 审美控制”写成连贯的短句：
  - 主体（描述）：核心对象的外观细节，用形容词或短句；人物写年龄、服饰、发型和神态，物体写材质、形状和颜色；
  - 场景（描述）：主体所处环境的细节，包括背景和前景；
  - 运动（描述）：运动的幅度、速度和效果，如“缓缓走近”“剧烈摇曳”“快速奔跑”，写清动作的先后顺序；
  - 审美控制：光源与光线环境（柔光、硬光、侧光、逆光、高对比度）、时间段、构图（中心构图、左侧重或右侧重构图）、色调（暖色调、冷色调、低饱和度）；景别、拍摄角度、镜头类型和运镜在 shotSize、cameraAngle、cameraMovement 里，程序会写在提示词最前面，所以 promptZh 里不要重复；
  - 风格化：整体画面风格由程序统一写在提示词开头，不需要在每个镜头里重复风格关键词。
  只描述画面中能看到的内容，用正向表达，不写“不要”“避免”之类的否定句，不写镜头编号、台词和旁白。
- 以上一镜头尾帧作为首帧的镜头（连贯要求里指明的，或 firstFrameMode 为 prev_tail），主体、场景和风格已由首帧图片确定，promptZh 改用图生视频公式“运动 + 运镜”的思路：重点写运动描述（幅度、速度和效果），主体和场景只用一句话点明、延续首帧，不再重新描绘外观；运镜仍填在 cameraMovement。
- promptEn 是完整的英文提示词，含义与 promptZh 一致，同样按“subject description + scene description + motion description + aesthetic control”的公式，并在开头写上景别、机位和运镜（英文提示词不会再拼接镜头语言字段），同样只描述画面、正向表达、不含台词。
- transition 写与下一镜头的转场，如“叠化”；普通硬切填“切”。
- 同一实体在各镜头中的外观、服装、位置和光线保持一致，需要保持的要求写进 continuityNote。
- 镜头覆盖整集的主要剧情，顺序与剧本一致，不得增加剧本没有的情节。

## 声音

- 台词、旁白、音效和背景音乐只写在 sounds 里，不要写进 promptZh、promptEn；程序会把它们编译进最终的提示词。
- 声音按声音公式填写：提示词 = 主体 + 场景 + 运动 + 声音描述（人声、音效、背景音乐）。
  - 人声（dialogue、narration）= 角色台词 + 情绪 + 语气 + 语速 + 音色 + 口音：台词填在 text，情绪、语气、语速、音色、口音填在 delivery，如“轻松的语气、适中的语速、清晰的嗓音”；
  - 音效（sfx）= 发声材质 + 动作 + 环境音：text 写清发声物体的材质、发出声音的动作和环境音，如“小玻璃球落在木地板上发出‘啪嗒’一声，室内很安静”；
  - 背景音乐（music）= 背景音乐/配乐 + 风格：text 写配乐的风格和氛围，如“悬疑风格的背景音乐”。
  声音要与镜头里的画面和动作对应，按镜头内出现的先后顺序排列。
