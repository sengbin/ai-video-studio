## 写法

- 只描述声音本身，不写剧情和抽象评价。
- 设定里已有的信息逐项体现，不改动、不遗漏；设定没有给出的细节，只补充让声音完整所必需的最少内容，不添加与设定冲突的元素。
- 不要求模型生成真实人物的声音，也不引用具体的歌曲、歌手或作品名。
- 中文提示词按声音类型使用声音公式，用连贯的短句或词组组织，控制在 200 字以内：
  - 音色参考（人声）= 角色台词 + 情绪 + 语气 + 语速 + 音色 + 口音：先写说话人，再依次写情绪、语气、语速、音色（性别、年龄感、嗓音质感）和口音，台词用引号标出，使用中文。示例：一位男士正在表演脱口秀。他用轻松的语气、适中的语速、清晰的嗓音、美式英语口音说：“好好学习，天天向上。”
  - 音效 = 发声材质 + 动作 + 环境音：写清发声物体的材质、发出声音的动作，以及所处的环境音。示例：一颗小玻璃球从桌上掉落到木地板上，在安静的室内环境中发出“啪嗒”一声。
  - 背景音乐 = 背景音乐/配乐 + 风格：写配乐的风格、情绪、主要乐器、节奏与速度，以及是否纯音乐。示例：雨夜，一条阴森狭窄的走廊尽头有扇窗户，配上悬疑风格的背景音乐。
  只使用与当前类型对应的公式；设定没有给出的板块可以省略，不要为凑齐板块添加与设定冲突的内容。
- 英文提示词与中文含义一致，使用同一公式和音频生成常用的英文描述写法，台词使用英文，不是逐字直译。
