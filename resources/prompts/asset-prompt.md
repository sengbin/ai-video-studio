## 写法

- 只描述画面里能看到的内容：外观、材质、颜色、光线、构图和背景，不写剧情、心理活动和抽象评价。
- 设定里已有的信息逐项体现，不改动、不遗漏；设定没有给出的细节，只补充让画面完整所必需的最少内容，不添加与设定冲突的元素。
- 视角与构图、背景、画面风格、参考图画幅有填写时必须体现；没有填写的不要自行规定画幅尺寸。
- 视角与构图是多视图版式（如三视图、三视图加正脸特写）时，在一张图里按设定写明各分区的位置和内容，各视图中人物或物体的外观、比例和服装保持一致。
- 画面中不出现文字、标识、水印和边框。
- 中文提示词按进阶公式“主体（描述）+ 场景（描述）+ 运动（描述）+ 审美控制 + 风格化”的顺序，用连贯的短句或词组组织，控制在 300 字以内：
  - 主体（描述）：画面的核心对象及其外观细节，用形容词或短句；人物写年龄、性别、服饰、发型和神态，物体写材质、形状和颜色，描述越具体越好；
  - 场景（描述）：主体所处环境的细节，包括背景和前景，如室内或室外、季节、天气；
  - 运动（描述）：参考图是静态画面，这一板块只写主体定格的姿态或当前状态，不写随时间展开的动作过程；
  - 审美控制：光源与光线环境（柔光、硬光、侧光、逆光、高对比度）、时间段（白天、夜晚、黎明）、景别（特写、近景、中景、全景、远景）、构图（中心构图、左侧重或右侧重构图）、拍摄角度（平视、俯拍、仰拍、顶视）、镜头类型（广角、长焦、微距）、色调（暖色调、冷色调、低饱和度）；
  - 风格化：画面的视觉风格，如写实摄影、水彩、国风、赛博朋克、线稿插画、3D 卡通、像素风格、黏土风格。
  设定没有给出的板块可以省略，不要为凑齐板块添加与设定冲突的内容。
- 英文提示词与中文含义一致，同样按“subject description + scene description + motion (static pose or state) + aesthetic control + style”的顺序，使用图像生成常用的英文描述写法，不是逐字直译。
